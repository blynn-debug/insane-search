# data_map_verify.md — 지도 확인 체크리스트

> cowork.md 단계 [2]에서 호출. 텍스트로 절대 얻을 수 없는 정보 = 사람이 지도 보고 답해야 함.
> v1은 *체크리스트 응답 paste* 방식. v2 백로그에 LLM 시각분석 표시 (Q3 보류 영역).

---

## 0. 사용 원칙

- cowork은 인터럽트 B 시점에 이 체크리스트 전체를 **한 번에** 발송
- 사용자는 *항목별 응답*을 paste로 회신 (자유 형식 허용)
- 항목 누락 시 eval_rubric §0에 따라 자동 감점

### 0.1 권장 지도 도구
| 용도 | 도구 |
|---|---|
| 배후수요 식별 | 네이버지도 / 카카오맵 (위성 + 일반) |
| 동선 추적 | 카카오맵 로드뷰 |
| 거리 측정 | 네이버지도 측정 도구 |
| 단지·세대 확인 | 호갱노노, 아실 |
| 행정 경계 | V월드 (https://map.vworld.kr) |

---

## 1. 배후수요 체크 (유효수요 평가 입력)

### 1.1 단지 인벤토리 (반경 500m)
- [ ] **물건지에서 도보 5분 거리(약 400m) 내** 모든 아파트·오피스텔·빌라 단지 식별
- [ ] 각 단지별 응답 양식:
  ```
  - [단지명] | [세대수] | [물건지로부터 거리 m] | [물건지와의 동선 관계*]
  ```
  *동선 관계: 정문이 물건지 향함 / 후문이 물건지 향함 / 무관 / 도로로 단절

### 1.2 단절 요소
- [ ] 6차선 이상 대로 사이 있음? (Y/N)
- [ ] 하천·철도·고가도로 등 물리적 장벽? (Y/N)
- [ ] 단지 출입구가 반대편에 있어 배후세대 절반만 유효? (Y/N)

### 1.3 원룸촌 여부
- [ ] 다세대·빌라·고시원 밀집? (Y/N)
- [ ] 대학·산업단지 근처? (Y/N) — 원룸촌 시그널
- [ ] 20~30대 단신 가구 비중 추정 (高/中/低)

---

## 2. 주동선 체크 (가장 중요)

### 2.1 보행 동선 식별
- [ ] **퇴근/하교 동선이 물건지를 지나는가?** (Y/N)
  - 지하철역 → 아파트 단지 정문 사이 경로에 물건지가 있는지
- [ ] **물건지가 동선의 어느 쪽인가?**
  - 퇴근 방향 기준 오른쪽 / 왼쪽 / 정면 / 후면
  - (집대신상가투자 원칙: *퇴근길 오른쪽이 유리* — 퇴근 후 즉시 들르기 좋음)
- [ ] 출근 동선만 해당? (Y/N) — 매출 절반 이하
- [ ] 동선의 **시작점**(역·정류장)에서 물건지까지 거리 m
- [ ] 동선의 **끝점**(단지 정문)에서 물건지까지 거리 m

### 2.2 자동차 동선 (해당 시)
- [ ] 진입·진출 차량 동선과 일치? (Y/N)
- [ ] 주차 용이성 (高/中/低)

### 2.3 입지 형태
- [ ] **1층 코너**? (Y/N)
- [ ] 평면 입지? 2층 이상? 지하? (선택)
- [ ] 출입구 방향과 동선 일치? (Y/N)
- [ ] 간판 시인성 (高/中/低)

---

## 3. 흐르는 입지 판정 (4대 특성 체크)

각 항목 Y/N로 답하면 cowork이 §1.3 룰로 자동 채점.

### 3.1 대로변 + 유동인구 많음
- [ ] 6차선 이상 대로변에 위치? (Y/N)
- [ ] 버스정류장 인접 (50m 이내)? (Y/N)
- [ ] 시각적으로 유동인구가 많아 보임? (Y/N)

### 3.2 이면 유효수요 압도
- [ ] 대로변 너머 이면에 **아파트·주거지 밀집**? (Y/N)
- [ ] 이면 단지에 **자체 상가 또는 시장** 존재? (Y/N)
- [ ] 이면 상권이 물건지보다 활성화되어 보임? (Y/N)

### 3.3 광역상권에서 1입지 아님
- [ ] 같은 역세권/대로 내에 **더 좋은 코너 또는 사거리 1입지가 따로 있음**? (Y/N)
- [ ] 물건지가 상권의 시작점에서 떨어진 끝자락? (Y/N)

### 3.4 면적 작음
- [ ] 전용 30평(99㎡) 미만? (Y/N)
- [ ] 단일 업종만 가능한 협소 점포? (Y/N)

> 4개 모두 Y면 §1.3 즉시탈락 F-04. 3개 Y이어도 매우 위험.

---

## 4. 경쟁점·동종업종 (예상 업종 입력 필요)

### 4.1 검토 업종 입력
- 입점 예상 업종: [편의점 / 베이커리 / 커피 / 치킨 / 화장품 / 기타: ____]

### 4.2 동선상 경쟁점 식별
- [ ] 같은 동선상에 동종 점포 존재? (Y/N, 있으면 거리 m)
- [ ] 경쟁점이 **물건지보다 동선상 앞쪽**(역에 더 가까움)? (Y/N)
  - 앞쪽이면 = 손님 가로채기 당함
- [ ] 경쟁점 브랜드·규모 (예: GS25 vs CU 동등 / 본점 vs 가맹점)

### 4.3 다른 업종 클러스터
- [ ] 식음 클러스터(음식점 5개 이상 모임) 인접? (Y/N) — 집객 효과 +
- [ ] 학원·병원 등 집객시설 인접? (Y/N)

---

## 5. 학교·정화구역 (법률 리스크)

### 5.1 학교 위치
- [ ] **반경 50m 내** 초·중·고? (Y/N) — F-01 후보
- [ ] **반경 200m 내** 초·중·고? (Y/N) — F-02 후보
- [ ] 학교명·거리 명시:
  ```
  - [학교명] | [거리 m] | [학교 경계 기준]
  ```

### 5.2 다른 규제 시설
- [ ] 군부대 200m 이내? (Y/N)
- [ ] 종교시설 인접 (영업 제한 가능)? (Y/N)

---

## 6. 토지 매물 한정 추가 체크

### 6.1 접도 확인
- [ ] 도로에 접해 있음? (Y/N)
- [ ] 접한 도로 폭: ____ m (4m 미만이면 건축 불가능 위험)
- [ ] 도로가 **현황도로**인지 **지적도상 도로**인지?

### 6.2 인접 토지 활용
- [ ] 인접 토지 활용 상태 (예: 인접에 신축 빌라, 농지, 공장 등)
- [ ] 인접 토지의 용도지역과 차이?

### 6.3 호재 단서
- [ ] **택지지구 인접** (5km 이내)? (Y/N, 지구명 명시)
- [ ] **IC·역사 신설 계획 인접**? (Y/N)
- [ ] **지구단위계획 변경 고시 발표**? (Y/N)

### 6.4 농지·임야 특수
- 농지: 농업진흥구역 해제 사례가 **인접 농지**에 있는가? (Y/N)
- 임야: 평균 경사도 추정 (지도상)? (10°/15°/25°/그 이상)
- 임야: 분묘 다수? (Y/N)
