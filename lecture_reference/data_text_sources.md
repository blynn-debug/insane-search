## 0. 데이터 우선순위

| 등급 | 의미 | 누락 시 영향 |
|---|---|---|

## 1. 토지·건물 기본 정보

### 1.1 토지이용계획 (필수)
- **출처**: 토지이음 (https://www.eum.go.kr)
- **조회**: 지번 입력 → 토지이용계획 열람
- **추출 항목**:
  - 지목 (필수)
  - 용도지역·용도지구·용도구역 (필수)
  - 면적 (필수)
  - 개별공시지가 (중요)
  - 행위제한 사항 (중요)
  - 다른 법령에 따른 지역·지구 (예: 정화구역, 가축사육제한구역, 군사시설보호구역)
- **paste 방식**: 페이지 텍스트 그대로 복사 → cowork 입력 칸에 붙여넣기
- **v2 자동화**: 토지이음은 공공 API 미제공, 스크래핑 가능 (안티봇 약함)

### 1.2 건축물대장 (중요 / 상가·상가주택만)
- **출처**: 정부24 또는 세움터 (https://cloud.eais.go.kr)
- **추출 항목**:
  - 건축물 용도 (예: 제1종근린생활시설)
  - 연면적, 건폐율, 용적률
  - 사용승인일 (노후도 평가)
  - 주용도·부속용도
  - 위반건축물 여부
- **paste 방식**: PDF 다운로드 → 텍스트 추출 또는 핵심 항목 수기 정리

### 1.3 등기부등본 (중요 / NPL 매물 필수)
- **출처**: 인터넷등기소 (https://www.iros.go.kr)
- **추출 항목**:
  - **표제부**: 소재지, 면적, 용도
  - **갑구**: 소유권 변동 이력, 가압류, 가처분
  - **을구**: 근저당 (1순위/2순위/3순위 채권최고액·설정일), 전세권, 임차권
- **NPL 특수 점검**:
  - 1순위 근저당 = NPL 매입 대상
  - 선순위 임차권 + 대항력 有 → 위험
  - 가압류 후순위인지 선순위인지

### 1.4 토지대장 (참고)
- **출처**: 정부24
- **용도**: 지번·면적·소유자 변동 이력 확인

## 3. 인구·수요 데이터

### 3.1 행정동 인구·세대 (중요)
- **출처**: 행정안전부 주민등록 인구통계 (https://jumin.mois.go.kr) 또는 KOSIS
- **추출 항목**:
  - 행정동 총 인구
  - 세대수
  - 연령대 분포 (20~30대 비중 = 원룸촌 시그널)
- **활용**: 유효수요 평가의 거시적 보조

### 3.2 단지별 세대수 (필수 / 유효수요 평가)
- **출처**: 
  - 네이버부동산 (단지 정보)
  - 호갱노노 (https://hogangnono.com)
  - 아실 (https://asil.kr)
- **추출 항목**: 반경 500m 내 모든 단지의 세대수·연식·평형 분포
- **paste 방식**: 단지명 + 세대수 리스트 (예: `광장힐스테이트 1,200세대`)

### 3.3 통계지리정보 SGIS (참고)
- **출처**: https://sgis.kostat.go.kr
- **활용**: 격자단위 인구·사업체 데이터 (상권 분석 깊이 ↑)

## 7. 인터럽트 B 발송 시 체크리스트

```markdown
## 추가 입력 요청

### 필수 누락 (반드시 채워야 평가 진행)
- [ ] 지목:
- [ ] 용도지역:
- [ ] 면적:
- [ ] 매물 종류:
- [ ] 가격:

### 중요 누락 (없으면 감점)
- [ ] 인접 단지 세대수 (500m 내):
- [ ] 사용승인일 (건축물대장):
- [ ] 등기부 핵심 (근저당·임차권):
- [ ] 인근 시세 (3건 이상):
- [ ] 학교 200m 내 여부:

### 참고 정보 (있으면 paste)
- [ ] 거래사례:
- [ ] 임대시세:
- [ ] 행위제한:
```

## 8. v2 자동화 백로그

| 항목 | 자동화 난이도 | 우선순위 |
|---|---|---|
| 토지이음 스크래핑 | 中 | 高 |
| 건축물대장 API | 低 (공공 API 有) | 高 |
| 네이버부동산 스크래핑 | 中 (안티봇) | 中 |
| 호갱노노/아실 (단지정보) | 中 | 高 |
| 디스코·밸류맵 | 高 (유료 API 검토) | 中 |
| 학교 정화구역 GIS | 中 (지오코딩 필요) | 中 |
| SGIS 격자 데이터 | 中 (API 有) | 低 |
