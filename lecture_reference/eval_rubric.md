# eval_rubric.md — 평가 루브릭

> cowork.md 단계 [4]에서 호출. 트랙별 채점표, 70점 룰, 즉시탈락 항목.
> 모든 점수는 100점 만점. 70점 미만은 자동 FAIL.

---

## 0. 공통 원칙

### 0.1 70점 룰 (집대신상가투자 09장)
- **70점 이상**: PASS (입찰/매입 검토)
- **65~69점**: 조건부 PASS (보완 정보 확인 후 재평가)
- **70점 미만**: FAIL (탈락)
- 70점짜리 물건을 **60점 가격에 매입**하는 것이 이상적

### 0.2 95% 룰 (집대신상가투자 08장)
- 경매 나온 상가의 약 95%는 나쁜 물건
- 좋은 입지일수록 처음부터 점수가 잘 나옴. 점수가 안 나오면 미련 두지 말 것

### 0.3 즉시탈락 (Instant FAIL) — 점수와 무관하게 FAIL

| 코드 | 항목 | 근거 |
|---|---|---|
| F-01 | 학교 절대정화구역 내 (정문 50m 이내) | 학교보건법 |
| F-02 | 상대정화구역(학교경계 200m 이내) + 유흥업종 의도 | 학교보건법 |
| F-03 | 농림지역 + 보전산지 (개발 가능성 사실상 0) | 토지투자공식 |
| F-04 | 흐르는 입지 + 단독 매물 (이면 상권 압도적) | 집대신상가투자 22~24장 |
| F-05 | 4개의 눈 중 1개라도 0점 (유효수요 자체가 없음 등) | 집대신상가투자 |
| F-06 | 권리관계 치명적 결함 (선순위 임차권 + 미배당 등) | NPL 실무 |

## 1. 상가 트랙 (100점)

| 대항목 | 배점 | 세부 |
|---|---|---|
| 유효수요 (첫 번째 눈) | 25 | §1.1 |
| 주동선 (두 번째 눈) | 30 | §1.2 |
| 흐르는 입지 여부 (세 번째 눈) | 25 | §1.3 |
| 법률 리스크 (네 번째 눈) | 20 | §1.4 |

> 배점 근거: 주동선이 가장 높음. "유효수요는 양이지만 주동선은 매출 그 자체"이기 때문.

### 1.1 유효수요 (25점)

| 조건 | 점수 |
|---|---|
| 아파트 1,000세대 이상 (단지 내 또는 정문 동선) | 25 |
| 아파트 500~999세대 또는 오피스텔 600세대 이상 | 20 |
| 아파트 300~499세대 또는 오피스텔 300~599세대 | 15 |
| 아파트 300세대 미만, 오피스텔 300세대 미만 | 5 |
| 배후수요 식별 불가 | 0 → **즉시탈락 F-05** |

업종 가중 (선택, ±3점):
- 베이커리·커피전문점 검토 시 유효수요 **2,000세대 미만**이면 -3
- 편의점 + **원룸촌 300세대** 이상이면 +3 (원룸촌은 편의점 매출 ↑)

### 1.2 주동선 (30점)

| 조건 | 점수 |
|---|---|
| 퇴근길 동선 + 오른쪽 + 1층 코너 | 30 |
| 퇴근길 동선 + 오른쪽 또는 코너 (한 가지만 만족) | 25 |
| 출퇴근 동선 양방향 모두 해당 (역세권 등) | 22 |
| 출근길 동선 (퇴근 동선 아님) | 15 |
| 비동선 (배후만 있고 동선 아님) | 8 |
| 동선 정보 부재 (지도 확인 불가) | -10 (감점 적용) |

추가:
- 단지 내 상가는 주동선보다 **세대수**가 더 결정적 (§1.1과 부분 중복 보정: -5)

### 1.3 흐르는 입지 여부 (25점)

흐르는 입지 4대 특성 (집대신상가투자 22장):
1. 대로변, 유동인구 많음
2. 이면 유효수요가 대로변보다 압도적, 독립 상권 존재
3. 광역상권에서 해당 입지가 1입지가 아님
4. 물건 면적이 작음 (이면 경쟁점 흡수력 부족)

| 조건 | 점수 |
|---|---|
| 흐르는 입지 4특성 중 **0개** 해당 | 25 |
| 1개 해당 | 20 |
| 2개 해당 | 12 |
| 3개 해당 | 5 |
| 4개 모두 해당 | 0 → **즉시탈락 F-04** |

### 1.4 법률 리스크 (20점)

| 항목 | 감점 |
|---|---|
| 학교 절대정화구역 (50m 이내) | **F-01 즉시탈락** |
| 학교 상대정화구역 (200m 이내) + 일반업종 | -5 |
| 학교 상대정화구역 + 유흥업종 의도 | **F-02 즉시탈락** |
| 학원과 같은 건물에 노래방/유흥 (연면적 1,650㎡ 미만 또는 거리 미달) | -10 |
| 담배사업법 50m 룰 위반 (편의점 매물인 경우) | -10 |
| 행위제한 사항 부재 (또는 확인 불가) | -3 |
| 위반 사항 없음 | 20점 유지 |

## 2. 상가주택 하이브리드 트랙 (100점)

1층 상가 평가(상가 트랙 룰) + 주거 부분 평가(토지 트랙 일부) 가중평균.

| 구성 | 가중 |
|---|---|
| 1층 상가 부분 점수 (상가 트랙 §1 그대로) | 60% |
| 주거(2층 이상) 부분 점수 (§2.1) | 40% |

### 2.1 주거 부분 점수 (100점)

| 항목 | 배점 |
|---|---|
| 입지 (역세권/대로변 접근) | 25 |
| 노후도 / 사용승인일 (15년 이하 25점, 30년 이상 10점) | 25 |
| 토지 모양·접도·진입로 폭 | 25 |
| 임대 가능성 (원룸·투룸 수요) | 25 |

집대신상가투자 36장의 "돈 되는 상가주택 3가지 법칙" 참조:
1. 1층 상가가 영업 잘 되는 입지일 것
2. 주거 부분이 임대 잘 나갈 것
3. 토지 효율(건폐율·용적률) 높을 것

## 4. 농지 트랙 (100점)

토지 트랙(§3) + 농업진흥구역 가산:

| 항목 | 배점 |
|---|---|
| 토지 트랙 점수 (§3) | 80% 가중 |
| 농업진흥구역 해제 호재 | +20 보너스 (별도 만점 20) |

§4 보너스 세부:
- 인접 농지가 최근 3년 내 해제된 사례 有: +20
- 도시계획 변경 발표 + 농진구역 포함: +15
- 호재 없음, 단순 농지: 0

## 6. 정량 추정 가이드 (점수와 별개 출력)

### 6.1 예상 월세 (상가 매물)

`kb_상가_매출지도.md` 참조. 핵심 공식:
- **요식업: 월 매출의 10% = 적정 월세**
- **편의점: 일 매출 × 30 × 5~6%**
- 베이커리·커피: 매출 × 8~12%

### 6.2 적정 매입가 (NPL 한정)

```
적정 매입가 = (감정가) × (점수/100) × 보정계수
보정계수:
  - PASS (70점 이상): 0.60 ~ 0.75
  - 조건부 PASS (65~69점): 0.50 ~ 0.60
  - FAIL (70점 미만): 진행 불가
```

근거: "70점짜리 상가를 60점에 매입" 룰. 점수 기준 보정계수는 NPL 매입가율의 실무 안전마진.

## 7. 출력 시 필수 포함 사항 (cowork.md §7-7 연동)

평가 결과 출력 시 **다음 4가지를 반드시 명시**:

1. 총점 및 등급 (PASS/조건부/FAIL)
2. 대항목별 점수 분해
3. **감점 근거 TOP 3** (구체 수치·항목 명시)
4. 즉시탈락 코드 (있다면)

감점 근거 작성 예시:
- ✅ "유효수요 -10점: 인접 아파트 280세대로 500세대 기준 미달"
- ❌ "유효수요 부족" (수치·기준 없음, 재검토 불가)
