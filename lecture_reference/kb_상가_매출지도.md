## 0. 핵심 공식

### 0.1 적정 월세 산식 (요식·서비스업 기본)
```
적정 월세 = 월 매출 × 10%
```
- 출처: 책 전반에 반복 강조 (요식업의 경우 매출 대비 적정 월세 10%)
- 임차인이 *영업해서 낼 수 있는 월세 수준*을 기초로 임대료 산정해야 함

### 0.2 업종별 보정
| 업종 | 매출 대비 적정 월세 비율 |
|---|---|
| 일반 요식업 (한식·분식) | 10% |
| 편의점 | 5~6% (매출 대비 마진 낮음) |
| 베이커리 | 8~10% |
| 커피전문점 | 8~12% |
| 화장품 | 12~15% (마진 높음) |
| 아이스크림 (배스킨라빈스) | 10% |
| 패스트푸드 (롯데리아·맥도날드) | 8~10% |

> 가맹점주가 *영업이익 - 월세*를 가져가는 구조. 월세가 너무 높으면 임차인이 못 버팀.

### 0.3 분양사무실 함정 (반복 경고)
- 분양사무실 호가 월세는 **실제 가능 월세의 1.5~3배** 부풀려져 있음
- 예: 분양사 "월세 500만 원 가능" → 실제 가능 130만 원 (편의점 입점 가정)
- **호가 신뢰 금지. 매출 추정으로 역산해야 함.**

## 1. 업종별 매출 기준치 (책에서 추출)

### 1.1 편의점 (가장 자주 등장)
| 상권 유형 | 일 매출 |
|---|---|
| 우량 역세권 + 코너 | 200~400만 원 |
| 원룸촌 중앙 입지 | 150~250만 원 |
| 아파트 정문 동선 | 130~200만 원 |
| 평균 가맹점 | 130~170만 원 |
| 약한 입지 | 100만 원 이하 |

> 동탄 잎새점 사례: 보증금 2,000 / 월세 120 / 가맹점주 수익 1,200만 원

월세 환산:
- 일 매출 200만 원 → 월 매출 6,000만 원 → 월세 약 100~150만 원
- 일 매출 150만 원 → 월 매출 4,500만 원 → 월세 약 80~100만 원

### 1.2 베이커리 (파리바게뜨·뚜레쥬르)
- **유효수요 임계치: 2,000세대** (집대신상가투자 13장)
- 일 매출 170~250만 원이 일반적
- 월 매출 5,000~7,500만 원 → 월세 400~750만 원
- *파리바게뜨가 뚜레쥬르보다 잘되는 이유*: 입지 선정 능력 우월 (책 31장)

### 1.3 커피전문점

| 브랜드 | 일 매출 평균 | 월 매출 | 적정 월세 |
|---|---|---|---|
| 투썸플레이스 (평균) | 140만 원 | 4,200만 원 | 350~500만 원 |
| 투썸 (홍대 등 특수) | 560만 원 | 1.7억 | 1,500~2,000만 원 |
| 스타벅스 | (별도) | (지역 편차 큼) | 매출의 12% 내외 |
| 이디야커피 | 80~150만 원 | 2,400~4,500만 원 | 200~400만 원 |
| 빽다방 | 90~140만 원 | 2,700~4,200만 원 | 200~350만 원 |

특수 룰:
- **테이크아웃 비중 高 입지**: 도로 진행방향 오른쪽, 2층 비추천
- 커피전문점은 **외관 시인성** > 인테리어

### 1.4 패스트푸드·치킨

| 업종 | 일 매출 | 적정 월세 |
|---|---|---|
| 롯데리아 | 100~180만 원 | 매출의 8~10% |
| 맥도날드 | 200~400만 원 (드라이브스루 시 ↑) | 매출의 8~10% |
| 맘스터치 | 130만 원 (월 4,000만 원) | 300~400만 원 |
| BBQ·교촌 등 치킨 | 일 130~250만 원 | 매출의 10% |

### 1.5 화장품 (이니스프리·에뛰드)

| 위치 | 일 매출 | 적정 월세 |
|---|---|---|
| 홍대입구 에뛰드 | **1,000만 원** | 1,500만 원 |
| 서울대입구 일반 | 180만 원 | 200~270만 원 |
| 대학가·역세권 1입지 | 200~400만 원 | 300~600만 원 |
| 일반 동네 | 100~150만 원 | 130~220만 원 |

특수: **첫 번째 코너** 입지가 출구 앞보다 더 좋음 (서울대입구역 사례, 책 20장)

### 1.6 아이스크림 (배스킨라빈스)
- 일 매출 230만 원 (노원역 사례)
- 적정 월세: 매출의 10%
- *계절성 큼*. 여름 매출에 가중치 50% 이상

### 1.7 분식·국수·돈가스
- 일 매출 100~200만 원
- 적정 월세: 매출의 10%
- "국수와 돈가스 팔아서 월세 감당하기 쉽지 않다" — 책 인용

### 1.8 토스트·간식
- 일 매출 600만 원까지 가능 (천호역 사례)
- 단, *통행량 매우 많은 입지* 한정
- 일반: 일 200~300만 원

## 2. 상권 유형별 매출 패턴

### 2.1 역세권 (출구 앞)
- 가장 좋은 입지: **첫 번째 코너** (출구 바로 앞 ≠ 최고 자리)
- 출구 앞은 *유동인구*만 많고 *정주성* 떨어짐
- 첫 번째 코너 = 동선이 잠깐 멈추는 자리

### 2.2 대학가
- 화장품·치킨(맥주)·중저가 카페가 강세
- 학생들의 *모임 장소* 업종 우대
- 고려대역처럼 *학생이 안 오는* 역세권 함정 주의 (책 48장)

### 2.3 원룸촌
- **편의점 매출 최강**
- 베이커리·중대형 음식점은 약함 (가족 단위 X)
- 원룸촌은 *유효수요 300세대*면 편의점 입점 가능

### 2.4 아파트 단지 정문
- 베이커리·요식·중대형 마트 강세
- 편의점은 단지 내보다 정문이 더 강함 (단지 내는 *손님이 한정*)

### 2.5 신도시 (택지개발지구)
- **상권 활성화 3~5년** 걸림
- 분양가는 매우 비싸지만 실제 임대료는 절반 이하
- 동탄·위례·미사 사례 모두 *분양가의 50~70%* 수준에 임대 형성

### 2.6 유흥상권
- 야간 매출 비중 高. 평일 vs 주말 편차 큼
- 편의점이 의외로 잘됨 (24h 수요)
- 베이커리는 약함

### 2.7 지식산업센터 (구로디지털·가산 등)
- 평일 점심·야근 수요 집중
- 주말·공휴일 매출 급락
- 편의점·도시락·간단한 한식 강세

## 3. 아메바 지도 그리기 (책 TIP 추출)

### 3.1 정의
- **아메바 지도** = 해당 입지의 *영향력이 미치는 범위*를 지도 위에 그린 것
- 모양이 정해져 있지 않음. 동선·장벽·경쟁점에 따라 늘어나고 줄어듦.

### 3.2 작성 방법
1. 후보 입지를 지도 위에 표시
2. 그 입지로부터 **도보로 무리없이 올 수 있는 거리** 경계선 긋기 (보통 반경 300~500m)
3. 경계선을 *대로·하천·철도·장벽*으로 잘라냄
4. 경쟁점 영향권을 빼냄
5. 남은 영역이 *이 입지의 실 상권*

### 3.3 활용
- 후보지 A와 B의 아메바 지도를 비교 → 면적 큰 쪽이 매출 크게 나옴
- 단순 직선거리·세대수보다 *훨씬 정확*

### 3.4 cowork 적용
- v1은 사용자가 직접 그려서 paste (텍스트 묘사 가능)
- v2: 지도 이미지 분석으로 자동 생성 (Q3 보류 영역)

## 4. 매출 → 적정 매입가 산출 흐름

```
1. 입지 정보 (지도 확인) → 예상 업종 결정
2. 업종별 매출 기준치 적용 → 예상 일/월 매출 추정
3. 적정 월세 = 매출 × 업종별 비율
4. 임대 수익률 가정 (보통 4~6%, NPL은 7% 이상도 목표)
5. 적정 매입가 = (월세 × 12) / 수익률
```

### 예시
- 광장동 1층 상가, 예상 업종: 편의점
- 입지 평가: 원룸 + 아파트 정문 동선 → 일 매출 180만 원 예상
- 월 매출 = 180 × 30 = 5,400만 원
- 적정 월세 = 5,400 × 5.5% = 297만 원 → 약 300만 원
- 수익률 5% 가정 → 적정 매입가 = (300 × 12) / 0.05 = **7.2억 원**
- 수익률 6.5% 가정(NPL) → 적정 매입가 = **5.5억 원**

## 5. 주의·경고 (책 전반 인용)

### 5.1 매출 자료보다 매입 자료를 요구하라 (책 06장)
- 매도자가 제시하는 매출은 *부풀려져 있을 가능성*
- 대신 **매입 자료**(원재료 발주 내역)를 요구하면 매출 역산 가능
- 예: 편의점이 본사에서 발주한 원가가 월 3,000만 원이면 매출 약 4,500만 원

### 5.2 망하는 입지 vs 성공하는 입지 (책 07장)
- 망하는 입지 공통점:
  1. 흐르는 입지 (대로변 + 이면 압도)
  2. 동선 *벗어난* 골목 안쪽
  3. 유동인구만 있고 정주성 X
- 성공 공통점:
  1. 동선 위 + 코너
  2. 충분한 유효수요
  3. 경쟁점 약함

### 5.3 도시 외곽에도 좋은 상가 많다 (책 11장)
- 역세권만 좇지 말 것. 외곽 신도시 단지 정문은 도심 못지않은 매출.
- 단, *분양가가 적정한지*가 관건.
